## 一、产品定位与核心价值

### 1.1 系统简介

JSA（Japan Study Assist）是一款专为**日本留学考学场景**深度定制的教育管理 SaaS 系统，覆盖学生管理、志愿学校跟踪、材料管理、时间线规划、成绩追踪等全流程。

### 1.2 核心差异化

| 优势 | 说明 |
|------|------|
| **深度垂直** | 专为日本留学场景设计：出愿时间、EJU/JLPT 成绩、研究科等 |
| **学校信息库** | 预设日本院校数据 + 自动补全，通用 CRM 不具备 |
| **三角色协作** | 管理员 / 老师 / 学生各有独立视角和权限 |
| **轻量高效** | 基于 Cloudflare 全球边缘网络部署，响应快、运维成本极低 |
| **移动端适配** | 响应式设计，手机端随时查看和操作 |

### 1.3 功能模块一览

| 模块 | 核心功能 | 价值层级 |
|------|----------|----------|
| 学生管理 | 档案 CRUD、分组标签、文理科筛选、搜索、转移 | 🟢 核心 |
| 老师管理 | 老师档案、部门分类、权限分配 | 🟢 核心 |
| 学校管理 | 志愿学校跟踪、学校信息库、自动补全 | 🟢 核心 |
| 材料管理 | 通用/学校专用材料清单、勾选状态、导出 | 🟢 核心 |
| 时间线 | 事件管理、卡片/线形/日历三种视图、拖拽 | 🟡 增值 |
| 近期可报 | 按月展示可报考学校、统计卡片 | 🟡 增值 |
| 权限系统 | 三角色（管理员/老师/学生）、7 类细分权限 | 🟢 核心 |
| 数据导出 | CSV、PDF、ICS 日历 | 🟡 增值 |
| 成绩记录 | JLPT / EJU 成绩管理、跟进备注 | 🟢 核心 |
| 系统设置 | 个人信息、密码修改 | 🟢 基础 |

## 四、定制化开发服务

### 4.1 定制化需求分级

| 级别 | 定义 | 典型需求 | 工期 | 参考报价 |
|------|------|----------|------|----------|
| **L1 - 轻度配置** | 不改代码，仅调整配置 | Logo 替换、品牌色调整、字段名称修改、默认选项配置 | 1 - 3 天 | ¥2,000 - 5,000 |
| **L2 - 界面定制** | 前端改动，不涉及数据模型 | 自定义报表模板、PDF 导出样式、Dashboard 布局、额外筛选条件 | 3 - 7 天 | ¥5,000 - 15,000 |
| **L3 - 功能扩展** | 在现有架构上新增功能 | 新增字段、自定义审批流程、新通知渠道（LINE / 企微）、批量操作增强 | 1 - 3 周 | ¥15,000 - 50,000 |
| **L4 - 深度定制** | 涉及数据模型和业务逻辑变更 | 多校区管理、自定义权限模型、第三方系统对接（财务 / CRM）、工作流引擎 | 1 - 3 月 | ¥50,000 - 200,000 |
| **L5 - 全定制/独立产品** | 基于 JSA 内核打造全新产品 | 白标产品、全套 UI 重设计、多国留学支持（韩 / 美 / 英）、从零搭建新模块 | 3 - 6 月 | ¥200,000 - 500,000+ |

### 4.2 工时制计费（适合 L1 - L3）

| 角色 | 日费率 | 适用场景 |

## 七、合同保护条款

在正式合同中务必约定以下条款：

| 条款 | 内容 | 原因 |
|------|------|------|
| **知识产权归属** | 定制代码中的通用组件归 JSA 所有，客户仅获得使用权 | 保留将通用功能产品化的权利 |
| **需求变更控制** | 超出原始需求范围的变更需另行报价，每次变更最多 2 轮 | 防止"需求蔓延" |
| **验收标准** | 以双方签字确认的需求文档为准，验收期限 7 个工作日 | 防止无限拖延验收 |
| **排他性限制** | 不承诺独家定制，除非客户支付独占费用（通常 3 - 5 倍） | 确保功能可复用 |
| **SLA** | 定义响应时间（4h / 工作日），不含 7×24 | 控制服务成本 |
| **退出条款** | 客户可导出全部数据，但无权获取源码（除非买断） | 防止客户拿走代码自行维护 |
| **数据安全** | 数据加密存储，定期备份，符合相关数据保护法规 | 增强客户信任 |
