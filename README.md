# 日本留学考学助手 - Japan Study Abroad Application

一个专为日本留学生和留学机构设计的考学管理系统，支持学生查看和老师管理两种模式。

## 功能特点

### 📱 完全响应式设计
- 移动端优先，完美适配手机、平板和电脑
- 流畅的动画效果和交互体验
- 支持触摸手势操作

### 👥 双角色系统
- **学生视角**：查看个人考学进度、时间线、材料清单
- **老师视角**：管理多个学生、编辑事项、跟踪进度

### 📅 核心功能模块
1. **时间线管理**
   - 考试、出愿截止、材料准备等重要日期提醒
   - 紧急事项标记和倒计时显示
   - 分类筛选和搜索功能

2. **学校管理**
   - 目标院校申请状态跟踪
   - 准备进度可视化
   - 学校要求和备注管理

3. **材料清单**
   - 通用材料和学校专用材料分类
   - 完成状态跟踪
   - 进度统计和导出功能

## 快速开始

### 安装依赖
```bash
npm install
```

### 开发模式
```bash
npm run dev
```
应用将在 http://localhost:3000 启动

### 构建生产版本
```bash
npm run build
```

### 预览生产版本
```bash
npm run preview
```

## 技术栈

- **React 18** - 用户界面框架
- **Tailwind CSS** - 原子化CSS框架
- **Lucide React** - 图标库
- **Vite** - 构建工具

## 项目结构

```

├── src/

├── package.json     # 项目配置
```

- 查看个人时间线和待办事项
